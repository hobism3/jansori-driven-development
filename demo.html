무엇을 보게 되나

A · 증거

빈 인덱스에서 시작

관련 스킬이 하나도 없는 정상 서버에서 업무를 끝내고, 제안 → 수락 → 캡슐 등록까지 갑니다. 잔소리가 자산이 되는 첫 순간입니다.

B · 교정

선배가 옆자리에 앉는다

결과를 보고 던지는 한 줄의 잔소리가 correction으로 캡슐에 박히고, 캡슐 버전이 올라갑니다. 같은 말을 두 번 할 필요가 없어집니다.

C · 세 상태

교정 전 / 후 / 정리 후

C0·C1·C2는 각각 새 세션입니다. 대화를 이어받지 않고도 결과가 달라지는지 — 즉 잔소리가 정말 전파됐는지를 확인합니다.

직접 돌려보기

  1. make run터미널 1에서 로컬 Jansori 서버를 띄웁니다. 한 번에 한 인스턴스만 운영합니다.
  2. make seed터미널 2에서 시연용 캡슐을 등록합니다. 같은 ID가 이미 있으면 덮어쓰지 않습니다.
  3. Plugin 활성화B/C 작업 공간에서 Claude Code Plugin을 켜고, /nag 와 /save 로 잔소리를 남깁니다.
  4. make verify실제 구현을 검증하고, 결과 스냅샷은 잔소리는 어디에 쌓이는가에서 그대로 확인합니다.
